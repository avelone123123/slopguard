# Security Policy
## Supported Versions
| Version | Supported |
| :--- | :--- |
| 2.9.x | Supported |
| 2.8.x | Supported |
| < 2.8 | Unsupported |
## Reporting a Vulnerability
Please report security vulnerabilities responsibly:
1. Open a private GitHub Security Advisory at `https://github.com/avelone123123/slopguard/security/advisories/new`.
2. Provide full reproduction steps, affected file types, and potential impact.
3. The core engineering council will triage and patch critical advisories within 24 hours.
## Security Principles
SlopGuard operates with zero telemetry exfiltration. All AST scans, diff analysis, and sanitizer passes run 100% locally on your machine with zero cloud dependencies.
